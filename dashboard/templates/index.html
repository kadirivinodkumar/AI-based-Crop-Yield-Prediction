AgriYield AI

CNN-LSTM Fusion for Precision Agriculture

🧠 Model Architecture

  • TimeDistributed ResNet CNN → BiLSTM (256-dim)
  • Stacked BiLSTM for weather time-series (128-dim)
  • Soft attention gate (crop-conditioned softmax)
  • Dense head: 256 → 128 → 64 → 1 (yield t/ha)

📦 Tech Stack

  • TensorFlow / Keras
  • scikit-learn · NumPy · Pandas
  • Flask · Chart.js
  • Matplotlib · Seaborn

🌾 Dataset

  • 1200 fields · 6 crops · 200 per crop
  • Real Sentinel-2: 5 bands + NDVI + EVI (7 channels)
  • Image patches: 32×32 px · 12 monthly timesteps
  • Weather: rainfall, temp, humidity, soil moisture + 2

🏆 Models Compared

  • Standalone CNN (spatial only) — R²: 0.708
  • Standalone LSTM (weather only) — R²: 0.091
  • 🏅 CNN-LSTM Fusion (proposed) — R²: 0.882
  • Random Forest — R²: 0.209 · SVR — R²: 0.181
